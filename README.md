# abhishek-chaudhary-legal-library
Legal Student Library for LLB and LLM students.
A digital academic library created to make legal study resources easier to access for law students.

## About

Abhishek Chaudhary Legal Student Library provides organized academic resources for LLB and LLM students in one place.

## Resources

The library includes:

- LLB Notes
- LLM Notes
- Previous Year Question Papers (PYQs)
- Bare Acts
- Important Case Laws
